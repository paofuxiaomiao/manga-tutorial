# AI漫剧制作教程

面向初学者的系统化 AI 漫剧制作教学网页，涵盖从剧本拆解到场景设定、真人感生成、镜头解析、分镜设计、拉片方法、工作流程，以及主流 AI 漫剧创作平台介绍。

## 内容模块

1. **制作概述** — AI漫剧制作全流程与常用工具链
2. **场景设定** — 快、准、狠三原则与AI场景设定技巧
3. **真人感生成** — 角色一致性与写实风格生成方法
4. **镜头解析** — 镜头语言与画面构图
5. **分镜设计** — 分镜脚本与画面规划
6. **拉片方法** — 从优秀作品中学习技巧
7. **工作流程** — 团队协作与质量把控
8. **创作平台** — Octo、Seko、RHTV、LibTV 四大平台介绍与对比

## 技术栈

- React 19 + TypeScript
- Tailwind CSS 4
- Framer Motion
- Wouter (路由)
